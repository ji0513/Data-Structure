\#  Queue



\## 1. 개념

\- \*\*FIFO (First In, First Out)\*\*: 선입선출 구조. 가장 먼저 들어온 데이터가 가장 먼저 나갑니다.

\- 예시: 줄 서기, 프린터 인쇄 대기열, 버퍼(Buffer)



\---



\## 2. 주요 연산

\- `enqueue()`: 큐의 맨 뒤(Rear)에 데이터 추가

\- `dequeue()`: 큐의 맨 앞(Front) 데이터 제거 및 반환

\- `peek()`: 맨 앞(Front) 데이터 확인

\- `isEmpty()` / `isFull()`: 큐가 비어있는지 / 가득 찼는지 확인



\---



\## 3. 큐의 동작 과정 및 종류

1\. \*\*선형 큐 (Linear Queue)\*\*: 배열을 일직선으로 사용 (데이터 삭제 시 공간 효율 저하 문제 발생)

2\. \*\*원형 큐 (Circular Queue)\*\*: 배열의 끝과 처음이 이어져 있는 구조 (공간 재사용 가능)
