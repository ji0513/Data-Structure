# Stack

## 1. 개념

Stack은 데이터를 한쪽 끝에서만 삽입하고 삭제할 수 있는 자료구조이다.

- LIFO (Last In First Out)
- 가장 나중에 들어온 데이터가 가장 먼저 나간다.
- 삽입과 삭제가 한쪽(top)에서 이루어진다.

## 2. 주요 연산
| 연산 | 설명 |
|------|------|
| push | 데이터 삽입 |
| pop | 데이터 삭제 |
| peek | 최상단 데이터 확인 |
| isEmpty | 스택이 비어있는지 확인 |
| isFull | 스택이 가득 찼는지 확인 |

## 3. 스택 동작과

### Push

데이터 삽입

↓

top 증가

↓

새로운 top에 데이터 저장

---

### Pop

top의 데이터 반환

↓

top 감소

---

### Peek

top의 데이터만 확인(삭제하지 않음)

---

### 예외 처리

- `isFull()` : 스택이 가득 찼는지 확인
- `isEmpty()` : 스택이 비어 있는지 확인
